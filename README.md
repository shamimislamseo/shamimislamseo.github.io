# Shamim Islam SEO — GitHub Pages

## Files
- `index.html` — main website + Google Search Console verification tag
- `style.css` — design
- `robots.txt` — crawler instructions
- `sitemap.xml` — XML sitemap

## GitHub Pages
Repository: `shamimislamseo.github.io`

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Website:
https://shamimislamseo.github.io/

## Google Search Console
The supplied verification meta tag is already inside `<head>` of `index.html`.

After GitHub Pages finishes deploying:
1. Open Google Search Console.
2. Add URL-prefix property:
   `https://shamimislamseo.github.io/`
3. Choose HTML tag verification.
4. Because the tag is already published, click Verify.
5. Then open Sitemaps and submit:
   `sitemap.xml`
