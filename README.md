# Shamim Islam SEO — GitHub Pages

A modern personal SEO portfolio website.

## Publish on GitHub Pages

1. Create a GitHub repository named `shamimislamseo.github.io`.
2. Upload `index.html`, `style.css`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open: `https://shamimislamseo.github.io/`

Before publishing, replace the LinkedIn URL in `index.html` with your actual profile URL.
